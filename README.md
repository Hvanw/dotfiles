## Installation
Before run scripts, make sure your "pwd" is $HOME directory. This script will create some symlink to your home

For Arch Linux:
```sh
$ ./scripts/install-on-arch.sh
```

For MacOS (arm64 - Apple Silicon chip):
```sh
$ ./install-on-mac
```
